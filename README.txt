HISOBCHI.UZ — HTML / CSS / JAVASCRIPT

Ishga tushirish:
1. ZIP faylni chiqarib oling.
2. index.html faylini Chrome, Edge yoki Safari brauzerida oching.
3. Internet bo‘lsa, Chart.js grafik kutubxonasi va Google Fonts yuklanadi. Asosiy funksiyalar CDN bo‘lmasa ham ishlaydi, ammo grafiklar ishlamasligi mumkin.

Fayllar:
- index.html — sahifa tuzilishi
- style.css — qora + shampan oltin dizayni
- script.js — funksiyalar va localStorage ma’lumot saqlash

Funksiyalar:
- Kirim va xarajat yozuvlari, qidirish, filterlash, o‘chirish
- Balans va oylik budjet hisoblash
- Daromad/xarajat grafiklari va kategoriyalar tahlili
- Qarzlar va jamg‘arma maqsadlari
- CSV hisobotni yuklab olish
- Mobil ekranlarga mos dizayn

Eslatma: Ma’lumotlar shu brauzerning localStorage xotirasida saqlanadi. Brauzer ma’lumotlarini tozalash ma’lumotlarni o‘chirishi mumkin. Bu frontend demo; foydalanuvchi akkauntlari, bulut sinxronlash va boshqa qurilmalarda umumiy kirish uchun backend kerak.
